# Wildroot Critters

Wildroot Critters is a creature-collecting adventure for macOS and Windows.

## Download and play

Download an official build from [Releases](../../releases). Choose the archive for your operating system, unzip it, and run the included application.

| Platform | Package | Notes |
| --- | --- | --- |
| macOS | `WildrootCritters-macOS.zip` | Universal Apple Silicon and Intel build. It is unsigned, so macOS may require right-clicking the app and choosing **Open** on first launch. |
| Windows | `WildrootCritters-Windows.zip` | 64-bit build. Windows SmartScreen may require **More info** then **Run anyway** on first launch. |

The published checksums are in `SHA256SUMS.txt`. Verify the archive before installing if you are comfortable using a terminal.
